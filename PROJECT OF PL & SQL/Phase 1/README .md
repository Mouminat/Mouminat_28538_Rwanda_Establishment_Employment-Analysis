# Rwanda Establishment Distribution and Employment Analysis System

## Project Overview

This project proposes an Oracle relational database and analytical reporting system based on selected information from the Rwanda Establishment Census 2023. It is intended to support analysis of establishment distribution and employment across dimensions such as district, economic activity and establishment size. The final fields and database structure will be confirmed after the source dataset and its documentation have been inspected.

**Course:** INSY 8311 – Database Development with PL/SQL  
**Data source:** National Institute of Statistics of Rwanda (NISR), Rwanda Establishment Census 2023  
**GitHub repository:** https://github.com/Mouminat/Rwanda-Establishment-employment-analysis

## Phase I – Business Process Modeling

**Selected business process:** Establishment and Employment Data Analysis and Report Generation.

This process describes how an analyst selects analysis criteria, submits a request, receives analytical results and requests a report. The analytical system validates the criteria, retrieves matching records from the census database and calculates relevant summaries. A manager or decision-maker reviews the generated report. A data administrator supports the process by maintaining the working analytical dataset.
